# Leçons

- Quand une préférence de maintenance est explicitement corrigée par l'utilisateur, remplacer l'approche recommandée dans la spécification plutôt que la défendre : ici, choisir WET avec un CSS complet par conférence, sans base partagée.
- Pour le compagnon de brainstorming, vérifier l’URL et le port courants après chaque relance ; le serveur peut être lié au PID éphémère de l’agent et une requête `HEAD` peut retourner 404 alors que la requête `GET` fonctionne.
